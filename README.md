# 抖音视频下载器

![CI](https://github.com/2708039738/douyin-downloader/actions/workflows/ci.yml/badge.svg)

把链接拖到 `下载.bat` 上 → 选一次水印 → 视频就进 `downloads/` 了。

- **无水印 / 带水印 / 两个都要**：每次运行都会问你，不会下错版本
- **清晰度**：最高画质 / 1080P / 720P / 540P，默认优先 H.264（播放器都能开）
- **批量**：一次可以拖多条链接，或者拖一个装链接的 txt
- **主页批量**：贴作者主页链接，按设定数量把他作品拉下来
- **顺手保存**：封面图 + 文案 txt（含作者、发布时间、点赞评论数据）
- **提取 MP3**：有 ffmpeg 就从视频音轨转；没有就退而求其次下抖音原声
- 纯 Python 标准库，**不需要 pip 安装任何东西**

## 需要什么

| 依赖 | 必需 | 说明 |
| --- | --- | --- |
| Python 3.9+ | 是 | 安装时勾选 "Add Python to PATH" |
| Edge 或 Chrome | 是 | 程序起一个无头浏览器，让抖音自己的 JS 去算签名；没有就拿不到视频地址 |
| ffmpeg | 否 | 只有「提取 MP3」要用。没有就退化成下载抖音原声（背景音乐） |
| 能上 douyin.com 的网络 | 是 | 系统代理会自动继承 |

**pip 包一个都不用**：下载走 `urllib`，DevTools 协议用的是手写的 WebSocket 客户端，
网页版用 `http.server`，全部标准库实现。所以没有 `requirements.txt` 这回事，
也不用建虚拟环境。

拿不准环境够不够，双击 **`环境检查.bat`**（等同 `python app.py --checkenv`），
它会逐项报告 Python 版本、浏览器、ffmpeg、网络，并告诉你缺的是必需项还是可选项。

## 怎么用

### 拖拽（推荐）

1. 把抖音链接（或整段分享文案）拖到 `下载.bat` 上
2. 第一次会问四个问题：清晰度、要不要 MP3、要不要封面文案、主页最多抓几个
3. 之后每次只问你「下载哪个版本」，选完就开跑

### 双击

双击 `下载.bat` 后，把链接粘进去，一行一个，输入空行结束。

### 网页版

双击 `网页版.bat`，浏览器会打开 `http://127.0.0.1:8765`，粘链接点按钮就行。
那个黑窗口要一直开着，关掉就等于退出；页面右上角有「服务已连接」的指示灯，
显示「未连接」说明窗口被关了，重新双击 `网页版.bat` 再刷新页面。

网页版和命令行走的是同一套下载逻辑：`config.json` 里的清晰度、`save_meta`、
`save_audio`、`out` 都对它生效；主页链接会自动拆成一个个作品排进队列。

### 命令行

```bash
python app.py https://v.douyin.com/xxxx/            # 会问你要哪个版本
python app.py 链接 --nowm                          # 直接下无水印
python app.py 链接 --watermark                     # 直接下带水印
python app.py 链接 --both --quality 1080           # 两个版本 + 指定清晰度
python app.py 链接 --audio --meta                  # 顺便 MP3 + 封面文案
python app.py https://www.douyin.com/user/xxxx --max 20    # 主页前 20 个
python app.py 链接列表.txt                          # 从 txt 批量读链接
python app.py --ui                                 # 打开网页版界面
python app.py --checkenv                           # 检查依赖是否齐全
```

完整参数看 `python app.py -h`。

## 文件去哪了

默认在程序目录的 `downloads/`，可以用 `--out D:\某目录` 改，
或者在 `config.json` 里写 `"out": "D:\\某目录"`（网页版也认这一项）。

每个作品会存成：

```
作者-文案[无水印].mp4
作者-文案[带水印].mp4
作者-文案[音频].mp3
作者-文案[封面].jpg
作者-文案[信息].txt
```

同名文件不会覆盖，会自动加 `(1)`、`(2)`。

## 设置

`config.json` 里存着默认值，直接改就行：

```json
{
  "quality": "auto",        // auto / 1080 / 720 / 540
  "prefer_h264": true,      // 优先 H.264，兼容性最好
  "save_meta": true,        // 保存封面 + 文案
  "save_audio": false,      // 顺便提取 MP3
  "profile_limit": 20,      // 主页链接最多取几个作品
  "out": ""                 // 下载目录，留空就是 downloads
}
```

改完不用重启，下一次任务就会用新值（网页版每次任务前会重新读一遍）。

删掉这个文件，下次运行会重新问一遍。

## 它是怎么工作的

抖音的详情接口必须带 `a_bogus` / `msToken` 这类签名参数，纯 HTTP 请求一律 403，
所以「把 URL 里的 playwm 改成 play」那些老办法现在基本都失效了。

这个工具换了个思路：起一个无头 Edge / Chrome，让抖音自己的 JS 去算签名发请求，
程序通过 DevTools 协议把 `aweme/detail` 的响应截下来。里面有两套地址：

| 字段 | 对应 |
| --- | --- |
| `video.bit_rate[].play_addr` | 无水印，多档清晰度 |
| `video.download_addr` | 带水印，官方下载版 |

每条作品开一个独立标签页，下完就关。整个浏览器进程在程序结束时退出，
不会在后台留东西。

## 常见问题

**第一次运行慢一点**
无头浏览器要启动，还要预热点一次首页拿 cookie，大约 3～5 秒。之后每条视频 2 秒左右。

**浏览器没有自动打开**
黑窗口里会打印一行 `地址：http://127.0.0.1:8765`，把它复制到浏览器就行。
也可以双击同目录的 `打开网页版.url`（每次启动都会自动更新成当前地址），
或者在黑窗口里输入 `o` 再回车，让程序再开一次。

**双击了两次 bat**
第二次会提示「已经有一个网页版在运行」，然后直接把已有页面打开，不会起第二个服务。

**提示「无法创建浏览器标签页」或 502**
程序内部的无头浏览器被关掉了（杀软、任务管理器、或者手动清了进程都会这样）。
现在程序会自己重启它，点一次「重试」就行；如果一直不行，重新双击 `网页版.bat`。
要是残留了太多无头进程，跑 `python app.py --cleanup` 清一遍。

**提示「解析超时」或「没有返回作品数据」**
作品被删了、设成私密、需要登录，或者网络被拦。公开作品才能下。

**提示找不到 Python**
装一个 Python 3.9+，安装时勾选 "Add Python to PATH"。

**下下来的文件播放器打不开**
下到了 H.265（HEVC）版本，卡片上会标 `H.265`。
在 config 里保持 `prefer_h264: true`，或者用 `--quality 1080` 就能拿到 H.264。

**想要 MP3 但提示没找到 ffmpeg**
装个 ffmpeg 并加进 PATH，或者用 `--ffmpeg D:\ffmpeg\bin\ffmpeg.exe` 指过去。
没有也能用：程序会改成下载抖音原声（背景音乐，可能不含人声）。

**带水印的为什么只有 720P**
抖音官方下载接口本身只给 720P 带水印版，不是程序限制。

**主页只抓到了一部分**
主页是滚动加载的，程序会自己往下滚；如果作者作品很多、或者需要登录才能看全，
调大 `profile_limit` 多试一次。

## 开发与测试

改动代码后，跑一遍测试就知道有没有弄坏别的东西：

```bash
python -m unittest discover -v
```

- 113 个用例，不联网、不打开抖音、不需要 pip 安装，十几秒跑完
- 覆盖链接解析、清晰度选择、下载（含半路断线 / 谎报长度 / 空响应）、图集打包、
  文案封面落盘、网页版接口、配置读写
- `tests/test_adversarial.py` 专门从攻击者角度写：伪造 `Host` / `Origin` 的十几种绕过写法、
  PID 复用时的误杀、畸形 `Content-Length`、任务 id 并发撞号、路径穿越
- 每次 push / PR 会自动在 **Windows / macOS / Linux × Python 3.9 / 3.11 / 3.13** 上跑一遍，
  配置在 `.github/workflows/ci.yml`

`.bat` 文件必须保持 CRLF 换行（cmd.exe 对 LF 会解析错位），`tests/test_app.py` 里有一条测试专门盯着这件事。
